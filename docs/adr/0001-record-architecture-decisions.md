# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-18

## Context
Decisions made with AI assistance are easy to lose between sessions.

## Decision
Record every significant architectural decision as a numbered ADR in `docs/adr/`, using `0000-template.md`.

## Consequences
Decisions are reviewable and traceable; Claude reads ADRs before proposing changes.
